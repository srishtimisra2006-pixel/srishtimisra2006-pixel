## A few things I've built

### [ModelGuard — ML Model Risk Auditor](https://github.com/srishtimisra2006-pixel/ModelGuard-ML-Audit-Engine)

A team project focused on making ML models easier to evaluate and audit. It checks data quality, model performance, potential data leakage, and group-level performance differences, then generates an HTML audit report.

### [Resume–Job Matching using NLP](https://github.com/srishtimisra2006-pixel/NLP-Resume-Job-Matching)

A team project exploring how NLP can help connect resumes with relevant job opportunities. It combines TF-IDF, Sentence Transformer similarity, and skill matching to rank job descriptions and identify matched and missing skills. Since the dataset has no labelled resume–job matches, the project does not claim a validated accuracy score.

### [FYNTRA — Annual Report Q&A](https://github.com/VivK1-2/FYNTRA)

A team project at SAII that explores how people can interact with company annual reports through questions and answers grounded in quoted passages from the filings. The repository is maintained under a teammate's account.

### [Student Performance Dashboard](https://github.com/srishtimisra2006-pixel/student-performance-dashboard)

A dashboard built around the UCI Student Performance dataset to explore student data and identify patterns through interactive visualisations, using Pandas, Plotly, and Streamlit.
